# Свое время

Демонстрационный прототип электронной очереди для парка "Вокруг света" в Омске, версия r12: полоса пути до «Пора идти» и QR-карта в телефоне.

https://konstantinpopov89.github.io/vokrugsveta-queue-demo/

Запись, баланс, списание и уведомления показаны в модели. Реальной интеграции с Лаймом и приема платежей нет. Учебные параметры и ограничения указаны в интерфейсе.
